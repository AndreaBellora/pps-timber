## Data access

Require access to the [it-hadoop-nxcals-pro-analytics](https://gms.web.cern.ch/group/it-hadoop-nxcals-pro-analytics/details) e-group in order to access the data.

## Installation

Simply run `source setup.sh` every time you start working with this code.

## Scripts

### Search variables

Call `python search-variables.py` and you'll be able to look into the available variables by inserting a pattern (maybe web TIMBER is still better)

### Plot variables

Call `python test-plot.py` to produce an interactive plot. To change the variables and time ranges, edit the first lines of the script.
